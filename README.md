### Анализ загрузчика шелл-кода (Linux)

Программа создаёт дочерний процесс, который находит
исполняемые регионы памяти родителя через /proc/<pid>/maps и внедряет туда
шелл-код с помощью ptrace. Шелл-код расшифровывается XOR с ключом 127 и
запускает /bin/sh. Под отладчиком ptrace_attach не срабатывает, поэтому тот
же вызов работает и как антиотладка. Родительский процесс в это время
забивает терминал случайным hex, чтобы выглядеть легитимно.
